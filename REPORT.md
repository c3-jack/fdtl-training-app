# Report

The game used to pop up "One away!" even when your four picks weren't actually close. It also let you tap a fifth tile after four were already selected, leaving the board stuck with the Submit button disabled and no explanation why. In the puzzle builder, picking a colour like Yellow from a group's dropdown would silently apply a different colour instead, so the colour you chose wasn't the colour you got. And solving the hardest, purple group used to show its words with no readable colour at all, so they were hard to make out against the purple background.

My agent helped most by moving fast across the codebase: for each defect it read the exact file and lines involved, cross-checked the behaviour against the GitHub issue's repro steps, and made a single, minimal, targeted change rather than rewriting anything nearby. It ran `npm run build` and `npm run lint` after every fix so mistakes surfaced immediately instead of at review time. One specific thing it got wrong: it found most of the defects by reading a git commit message rather than using issues and reproducing the issue in the running app — I still had to load the app and watch the corrected behaviour - ideally would have used something like playground.

I'd pick the "one away" fix in `src/lib/puzzle.ts` as the one worth explaining. That file holds the puzzle's rules as plain function, rather than it being part of a specific UI component. Fixing it there means the play screen, the state hook, and any future screen that checks a guess all get the correct behaviour automatically.

During the `filler-updates` merge, the decision was to keep every filler group from both sides of the conflict: my own new entry plus the three that branch already added, rather than resolving it by picking one side and moving on. The shortcut, deleting the incoming block or checking out only "ours," would have made the conflict disappear just as cleanly, but it would have quietly thrown away three category templates that other people in the cohort had already written and committed.
